# MeetingTutor 會議記錄轉錄器

目前 repository 處於「規劃與規格」階段，尚未開始實作。

文件入口：

- [附件判讀與需求來源](docs/00_附件判讀與需求來源.md)
- [產品規格書](docs/01_產品規格書.md)
- [開發手冊](docs/02_開發手冊.md)
- [實施路線圖與驗收計畫](docs/03_實施路線圖與驗收計畫.md)

規劃目標是建立一個可部署至 GitHub Pages 的靜態前端：以瀏覽器端 Whisper 進行語音轉錄，讓使用者自行提供並測試 OpenAI、xAI／Grok、Google 或 CGU 的 API Key，再以使用者選定的文字模型修飾語句、參照 PDF／文字資料並產出會議文件。任何實作前，應先完成文件中的 CGU API 契約、隱私、模型授權與瀏覽器相容性確認。
