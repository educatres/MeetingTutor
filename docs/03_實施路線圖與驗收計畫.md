# MeetingTutor 實施路線圖與驗收計畫

狀態：MVP 已完成第一版；M5 部署後驗收與後續功能仍待進行。

## 1. 里程碑

### M0｜契約與風險確認

- 確認 CGU 正式 API 契約、CORS 與模型列舉能力。
- 確認 Whisper／Transformers.js 模型授權、繁中效果、瀏覽器最低版本與下載大小。
- 確認 GitHub Pages repository、網域、授權與隱私聲明。
- 產出：決策紀錄、provider fixture、支援矩陣。

### M1｜資料核心與逐字稿工作區

- 建立 `MeetingProject` schema、IndexedDB、匯入／匯出。
- 完成音訊檔／麥克風 UI、Worker 介面、假轉錄 fixture。
- 完成段落、時間碼、說話者與原文／修訂文編輯。
- 閘門：不接任何真實 LLM 也能完整編輯與復原。

### M2｜瀏覽器端轉錄

- 接 Whisper adapter，加入進度、取消、模型快取、WASM fallback。
- 用繁中與不同音質 fixture 驗證時間碼與錯誤訊息。
- 閘門：主執行緒不凍結，轉錄失敗不遺失原始音訊／文字。

### M3｜Provider 與參考資料

- 完成 OpenAI、xAI、Google adapter 的 mock 與 opt-in 整合。
- 完成 CGU 契約後再實作；契約未確認前只保留明確的 blocked 狀態。
- 完成 PDF／TXT／MD 抽取、詞彙表與片段檢索。
- 閘門：Key 永不出現在匯出、URL、log 或 repository。

### M4｜生成與會議文件

- 建立 prompt version、結構化 schema、diff review、重試與拒絕。
- 依 `AGENTS.md` 產生四份 Markdown 與 A4 HTML。
- 加入 DEC／ACT 一致性 validator 與待確認附錄。
- 閘門：fixture 中所有編號、負責人、期限、狀態跨輸出一致。

### M5｜GitHub Pages 與發布驗收

- Actions build／deploy、相對路徑、CSP、無網路 A4 HTML。
- Chrome／Edge／Firefox／Safari 基本流程與無 WebGPU fallback。
- 隱私聲明、使用說明、錯誤回報與版本資訊。
- 閘門：未配置 Key 仍可使用本地轉錄與文件編輯；所有外送都需使用者確認。

## 2. 驗收案例

| Case | 情境 | 預期結果 |
|---|---|---|
| AC-01 | 匯入可解碼音訊 | 顯示 metadata、可轉錄、可取消、可下載原文 |
| AC-02 | 麥克風拒絕 | 顯示權限說明，仍可改用檔案匯入 |
| AC-03 | 無 WebGPU | 自動使用 WASM／提示效能差異，不白畫面 |
| AC-04 | 正確 provider Key | 測試成功，模型清單來自 API，使用者可選模型 |
| AC-05 | 錯誤／過期 Key | 不顯示秘密值，分類為 401／配額／網路／CORS，允許重試 |
| AC-06 | Google／xAI／OpenAI | 各自 adapter 對應正確欄位，統一回傳 ModelInfo |
| AC-07 | CGU 尚無 CORS | 清楚顯示未支援原因，不偽造模型清單，不把 Key 傳往未知位置 |
| AC-08 | PDF 含姓名與術語 | 顯示頁碼來源，候選詞需確認，原文可復原 |
| AC-09 | LLM 輸出不合 schema | 保留原文，顯示重試／人工編輯，不寫入正式輸出 |
| AC-10 | 缺日期／主責／期限 | 產出 `待確認`，列入待確認附錄與下次議程 |
| AC-11 | 多個決策與待辦 | DEC／ACT ID 在通知、紀錄、追蹤與 A4 HTML 一致 |
| AC-12 | A4 HTML 離線列印 | 無網路可開啟；A4 直式、按鈕隱藏、長文字換行、無外部依賴 |
| AC-13 | 重新整理／刪除專案 | 非秘密資料按使用者選擇保存；刪除後不可在 UI 取回 |
| AC-14 | 惡意文字輸入 | `<script>` 等只以文字顯示，不執行、不破壞 HTML |

## 3. 風險與對策

| 風險 | 影響 | 對策 |
|---|---|---|
| 瀏覽器記憶體不足 | 長音訊／大模型失敗 | Worker、分段、模型大小提示、可取消、MVP 設上限 |
| Whisper 繁中或人名錯誤 | 會議紀錄失真 | 原文保留、詞彙表、參考資料、diff、待確認標記 |
| LLM 幻覺 | 錯誤決策／待辦 | 結構化 schema、來源依據、禁止虛構、人工核准 |
| API Key 外洩 | 使用者費用／資料風險 | 記憶體暫存、CSP、無 log、無 URL、外送確認、XSS 防護 |
| CORS／供應商 API 改版 | provider 無法使用 | adapter 隔離、contract tests、清楚錯誤、CGU 先做契約確認 |
| GitHub Pages 無後端 | 無法代管秘密／代理 | 以本地處理與使用者直連為基線；relay 另案評估 |
| PDF 無文字層 | 參考資料空白 | 偵測掃描 PDF，標示需 OCR，不假裝完成 |
| A4 表格過寬 | 列印裁切 | 任務卡片、固定紙張 CSS、跨頁測試、離線 HTML |

5. 是否要加入手動「只修飾文字、不產生會議結論」模式？
